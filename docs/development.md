# 开发和弦

人员弹窗回归分别验证两位参与者的姓名、页面、跟踪按钮和行内留白；交换本端“我”标记、重排名单、改宽与替换人员后核对身份和坐标。标记仅在发送端可见、目标人员隐藏或离线、旧版比例锚点时隐藏，恢复目标后重新显示。隔离双端另保存修复前丢失姓名及重排后页面/按钮串行、修复后八点往返、双向实际 RPC、原生 HTML/焦点保持与最终绘制证据。

先读[架构边界](architecture.md)。源码位于 `src/`；根目录 `index.js`、`kernel.js` 是生成文件，不直接编辑。

同源嵌入的精度回归使用独立兄弟投影标记，先保持原元素完整边框盒尺寸，再去掉参照标记的边框和内边距。128 种组合覆盖分数尺寸、content-box/border-box、祖先及嵌套 CSS zoom、旋转/倾斜/翻转、独立 rotate/scale；逐层正反换算、跨布局字形与留白、反向捕获均要求误差小于 0.1 CSS px，并检查滚出视口和目标隐藏后不绘制。缩放可能改变浏览器原生字形的布局与边界，跨端参照必须使用接收端实际 Range，不能把按钮内固定偏移当成同一个字形位置。该回归不代表三维投影、所有原生组件或零丢帧已经验收。

## 项目结构

```text
src/
├─ protocol.js            共用协议验证与字段白名单
├─ kernel.js              在线会话与展示状态广播
└─ frontend/
   ├─ anchors.js          指针和选区锚点
   ├─ surfaces.js         页面、界面锚点、跟踪与快捷键
   └─ plugin.js           生命周期、菜单与多人状态展示
scripts/
├─ compile.cjs            生成加载入口
├─ check.cjs              清单、资源与翻译检查
└─ package.cjs            发布白名单打包及逐文件校验
tests/
├─ smoke.test.cjs         会话协议、断线和清理回归
└─ browser.test.cjs       DOM、Range、展示与原生编辑放行回归
```

源文件按固定顺序合并，无第三方运行时依赖。需要 Node.js 22 或以上，无需 `npm install`。

```sh
npm run compile
npm test
npm run check
npm run test:browser:once
npm run build
```

修改源码后先编译；测试检查源码和生成文件是否一致。浏览器回归默认监听 `127.0.0.1:18086`，打开终端打印的地址后执行并回传结果。`--once` 模式以测试结果退出；环境变量 `CHORD_BROWSER_PORT` 可更换端口。测试不再依赖 Lute。

焦点动画回归需要活动文档：加载后点击页面标题，避免切到其他验证页让浏览器节流动画。收起的下拉框使用独立 select/selectedcontent 参照验证纯文本字素、emoji、双向文字、RTL、改宽改字号、内容内边距、SVG 箭头位移、空选项及隐藏。私有、未知外观和旧比例锚点另行拒绝；选项 getter 抛错时也不得读取。原生隔离双端用设置语言控件验证实际字形与箭头，改变 value 仅作为不派发事件的测试探针，不触发语言设置。必须保存原生与参照文字的像素对比、实际 RPC、窄框被裁剪文字及仍可见的部分字形、不同选项下独立内边距、切换栏目和恢复，以及最终绘制位置。选项弹层自己的边框和留白另按下述独立边界测试验收，滚动条本体仍需适配。

原生下拉弹层回归需要真实用户激活：依次点击“展开原生下拉框进行层级验证”“关闭并重开原生下拉框”，重开后实际点击“第二项”。测试验证光标实际位于 picker 之上、字号及宽度变化、焦点保持、关闭隐藏与重开恢复，以及原生 input/change 各触发一次。混合方向文字另测全部字形与两端留白。隔离双端使用真实语言选项（不改变所选语言）检查中文、英文与阿拉伯语字形、四边留白、改宽改字号、隐藏和实际 RPC。关闭状态下的原生 select 内部文字与箭头另按上一段独立验收；picker 自身边框留白另有独立测试，滚动条本体仍待验证，不能由选项测试替代。

打包使用 Windows 自带 `tar.exe`，输出 `dist/package.zip` 和 SHA-256 校验文件。

## 通信

复用思源 Kernel RPC，不启动额外服务。

| RPC | 内容 |
| --- | --- |
| `presenceHeartbeat(sessionId, payload)` | 注册、名字、观看文档、页面与刷新代次 |
| `presenceRename(sessionId, name, generation)` | 修改显示名字 |
| `presenceLeave(sessionId, generation)` / `getStatus()` | 注销 / 在线状态 |
| `cursorUpdate(sessionId, generation, sequence, cursor)` | 指针锚点或 null |
| `selectionUpdate(sessionId, generation, sequence, selection)` | 文本选区或 null |
| `editingUpdate(sessionId, generation, sequence, editing)` | 当前聚焦的文档 ID、块 ID 或 null，无排他性 |
| `shortcut(sessionId, generation, sequence, keys)` | 只读组合键通知，无远端执行 |
| `cursorSnapshot()` / `setCursorTick(tick)` | 展示快照 / 共享频率 |

广播为 `presence-changed`、`cursor-changed` 与 `shortcut-shown`。页面参数先经共享协议验证、去除未知字段，再进入快照；不得携带搜索输入、剪贴板、密码、插件内部数据或任意可执行命令。不传选中的正文，会话密钥不出现在公共快照。参数必须验证 ID、类型、代次、序号和范围。

## 修改约定

- 展示与正文操作保持分离，不加入编辑权限或正文事件拦截。
- 覆盖层不接收鼠标事件，远端名字用 `textContent` 或转义后插入。
- 保留本地 Selection；远端选区使用 CSS Custom Highlight。
- 网络不可用时允许思源继续处理编辑；卸载清理自己的监听、定时器、覆盖层和高亮。
- 保持中英文键一致，不提交令牌、笔记、工作区配置或 IDE 缓存。

涉及展示交互的改动，需要在两个真实思源前端的临时文档中验证人数、光标、选区以及输入、拖拽和 Ctrl+Z。所有前端应加载同一版本；旧版本仍可能拦截编辑。

搜索预览回归覆盖同文档在正文、独立搜索标签、全局搜索弹窗及未引用预览中的隔离；验证文字、段落留白、标题、控件、面包屑留白、选区和编辑状态的隐藏/移除及旧锚点行为。完整插件回归验证相同块的光晕分组，以及搜索弹窗遮挡背景光晕。原生双端验收另测同名文档切换、关闭后主文档仍可见与重开。

资源搜索回归使用路径不同但同名同内容的原生结果行，验证预览字符、留白、查询高亮、结果重排、临时索引 ID 重建及隐藏；缺失路径、重复路径、畸形 ID、选中行歧义均拒绝绘制。原生双端验收分别覆盖搜索弹窗与独立搜索标签页，确认两者互不借用预览，并检查宽度改变后的本地字符及留白边界。

资源预览竞态回归在保持同一资源行选中的情况下替换过期内容，分别覆盖文字变化、仅显式换行位置变化、预览恢复、查询高亮与窗口自动折行。原生隔离验收可暂缓 getAssetContent 的真实响应，对四次切换产生的 24 种响应顺序逐个确认原生段落替换后再检查文字、外框留白与尾部锚点；验收结束恢复原始 fetch，不能把测试钩子打进发布包。

正文留白改动须验证字形前后和垂直间隙在改宽、字号、行高及滚动后的几何位置，以及新文字/媒体占位、原生选区和撤销。gap 的 side/ratio/可选 y 均须经过共享协议校验并由内核白名单复制，包含无效值拒绝和未知字段剥离测试；旧 space.x/y 的兼容断言应保留。

横排留白回归须覆盖平铺转分栏、左右列重排、双层嵌套、改宽、隐藏与撤销；期望位置直接按字形及测试列矩形计算。原生隔离双端另验真实块拖动、结构同步、Ctrl+Z、编辑光晕与悬浮菜单层级。选中文字拖动若没有实际文本移动，不得记作通过。

超级块容器上下边距另测首尾列与容器边界重合、空列、改宽、重排及临时选中；期望位置按子列和容器矩形独立计算。原生 sb__resize 平时 opacity 为 0，须通过真实悬停后采样，分别验证同一相邻块对移动到其他位置、隐藏及恢复；只在内核 API 中完成的重排不得记作原生拖动成功。

正文字形可见性须覆盖原生表格及代码的内部横向滚动、水平/垂直裁剪、同块内覆盖控件、pointer-events:none 和缩放。原生双端分别检查被裁文字隐藏、滚动露出恢复及新裁掉的另一侧隐藏；额外检查代码、表格行尾留白、公式与内联样式的本地几何。超长逐字输入不能假设归并为一次撤销；保留失败记录，区分单笔输入撤销与多个原生事务。


渲染源码浮窗回归覆盖不同块、同段相同内联公式、切换/重开、关闭、目标移除、输入值变化及缺少上下文。完整插件检查原生打开事件的订阅与卸载。隔离双端逐点验证标题、操作按钮、输入框区域、留白和缩放手柄，移动/实际改宽须确认矩形发生变化，并保存实际 RPC 接收记录；原生浮窗覆盖编辑光晕须保存视觉截图。源码字符回归以独立文本排版为期望，覆盖改宽换行、字体、缩放、中文、emoji、制表符、空行/行尾留白、水平/垂直实际滚动与内容变化；留白被文字占据时必须隐藏。检查焦点/选区不变、测量节点不泄漏及缺少字形分段能力时拒绝。原生双端保存真实输入/撤销、裁剪/滚动、实际RPC接收和原生字形选区像素证据；发布包不得含测试探针。撤销验证使用真实按键输入，模拟 type 方法可能不产生浏览器原生撤销记录。

公开搜索字段回归覆盖多行查询、资源搜索单行、占位文字、窗口改宽、原生水平/垂直滚动、内边距裁剪及内容变化；字形包含中文、emoji、组合与 ZWJ。双端原生搜索记录独立排版期望、实际 RPC、原生输入及撤销，不改正文。密码、私有、未知和文本遮掩字段检查值不进入内容哈希，遮掩值 getter 抛错也不得被读取。

命令面板搜索需覆盖原生默认 text 输入、亚像素宽度改成整像素宽度、水平滚动、不同查询、原生追加及撤销；旧 v2 控件比例锚点必须拒绝。搜索内边距四边分别采样，改宽和滚动后仍按内容边界匹配，查询变化保留可见 padding；移除 padding 时旧锚点须隐藏。内核对 field 边界验证 side 并清除额外属性。隔离双端须区分被裁剪的文字、有效行尾间隙和始终可见的内边距；原生滚动取整可能让最后字形延伸到内容边界外，此时没有可采样的行尾间隙，不能将 padding 冒充行尾。

PDF 查找回归覆盖同文件字素、占位文字、四周留白、改宽、原生水平滚动、输入及 Ctrl+Z、关闭重开，以及另一份 PDF 使用相同查询。校验文件指纹作用域独立于活动页，原生 wrapContainers 布局变化仍匹配，旧 v3 self 比例锚点拒绝；未知 PDF 模型、密码、私有与遮掩字段不读取值。隔离原生双端核验实际 RPC，确认查询原文未传输。

PDF 页码回归覆盖多位数字右对齐、前方留白、改宽与字号、改值、同路径文件指纹变化、旧比例锚点、无效数字和隐私边界。加载前后双向捕获与解析保持相同文字和留白；带背景图的 loading 状态不借用未装饰留白。原生双端调用工具栏加载入口并核对实际 loading 类、background-image 与最终光标。输入内容区零宽及零高时，只保留实际可见的内边距；恢复尺寸后数字恢复。隔离双端用原生方向键改页、输入“-”及 Ctrl+Z，并实际拖动分屏、展开侧栏和最大化。另一份 PDF 的相同可见页码不继承指针，原文件重开恢复；验证真实 RPC 和最终渲染点。原生步进按钮外观和 badInput 内部显示字符串尚不支持精确测量，不猜测位置。

滑块回归用独立普通元素参照核验焦点动画，覆盖多点圆点、值和宽度变化、RTL、端点剩余内边距、消失的轨道间隙、动态提示身份、媒体样式、旧整框比例及隐私边界，并检查卸载后测量样式清理。隔离原生设置双端用 16 与 41 的不同字号、原生方向键及 Home/End 验证圆点、轨道、上下留白和剩余内边距；切换栏目后隐藏，返回同栏目恢复。验证实际 RPC 及最终 DOM 绘制位置。已知尚未覆盖全部自定义外观、原生纵向控件和跨源样式。

弹层边框测试复用真实展开的用户激活，在独立固定的 left/top/width/height、边框及 padding 下采样四边与行间留白，改变尺寸和内边距后对照已知坐标。显式高度大于内容时底部空白也须保留。增加原生选项产生滚动条，真实 scrollIntoView 后验证视口不动、仍可见的边框/内边距继续精确映射、被选项占据或移出视口的留白隐藏；RTL 另测滚动条换边。测量前后原生子元素矩形、焦点、HTML 与实际滚动保持不变，所有测量节点清理。透明/私有/不支持的 picker 不绘制，内核验证四种 picker 边界并清除多余属性。隔离双端保存不同宽度字号、限高及两个滚动位置、反向、关闭/隐藏/恢复、实际 RPC 与最终弹层上的可见光标证据。原生滚动条的 thumb/track 和三维弹层仍是未完成范围，二维变换按后续局部平面矩阵验收。

相邻组件间隙回归分别覆盖横轴与纵轴：在原指针之外插入新可见组件，旧坐标仍为空白时也须隐藏；移除后恢复，同一对邻居改尺寸后按独立矩形核验，其他位置的组件不能影响该间隙。原生 picker 另插入绝对定位分隔组件，避免靠最终命中遮挡掩盖相邻身份错误。隔离双端以14px/200px和24px/280px语言控件双向验收，保存旧版错误接受、修复后隐藏/恢复、真实RPC与最终绘制；测量前后焦点及HTML不变。滚动条主题尺寸研究不得作为已支持thumb/track的验收。


网格和 flex 换行弹层使用独立固定列宽、行高、双轴 gap、边框和 padding，采样四边、横向间隙、纵向间隙与交叉点；改尺寸、125% zoom、实际滚动、RTL 双轴溢出后核对独立坐标。原相邻选项重排、关闭、隐藏栏目时隐藏，恢复后重新显示。另覆盖 CSS 锚点能力缺失时的横排 block 回退及 grid、垂排拒绝、table 计算为 block 但 overflow:visible 时拒绝。测量前后 HTML、焦点和选项矩形须不变。隔离思源双端用真实语言选项的 grid↔flex 布局保存双向参照、实际 RPC、绘制/关闭隐藏与性能证据；原生语言值及事件保持原样。

垂排原生弹层矩阵覆盖 vertical-rl/lr、sideways-rl/lr × ltr/rtl × block/grid/flex 共 24 组合。独立固定 CSS 坐标验证四边、内边距、不等高或不等宽选项间隙和交叉点，改尺寸与 125% zoom 后再测真实双轴滚动及 stable both-edges；选项越过边框时按原生命中判断，不将被选项占据的位置当作边框。源与目标 HTML、选项位置、焦点及滚动状态不受临时锚点影响，测量样式同步清理。
