# 使用和弦

和弦为连接同一思源内核的多个窗口展示在线名单、文档查看人数、共享光标和文本选区。正文同步、编辑、拖拽、保存、撤销和重做由思源自身处理，输入前无需申请编辑权限。

## 安装与更新

插件目录为 `<工作空间>/data/plugins/siyuan-plugin-chord/`。解压后 `plugin.json`、`index.js`、`kernel.js`、`index.css` 和 `i18n/` 应直接位于该目录。

启用后，顶栏直接显示“X 人在线”。点击人数打开思源原生人员弹窗，显示每人的当前页面；列表底部可改名和设置同步频率。

从带编辑锁的旧版升级时，先确认正文已保存并完成需要的个人撤销，再更新文件并在所有参与窗口重新启用插件。旧版个人撤销记录不会迁移；仍加载旧版的窗口可能继续拦截编辑。请使用同一版本连接同一内核。

## 在线参与者

初次加入从 `A` 开始分配名字，到 `Z` 后继续 `AA`、`AB`。名字可使用 1–24 个字符，不能与当前在线名字重复。名字是显示称呼，不是经过验证的账号。

文档树在文档 emoji 左侧显示观看人数，包含自己。点击人数查看该文档的名单；折叠目录展开后显示相应标记。

在线数按窗口统计。同一窗口刷新会尝试复用身份、名字、颜色和最近查看的文档；同一人打开两个窗口仍算两名参与者。sessionStorage 不可用时身份可能重建。异常离开的会话在约 90 秒无心跳后，由最多每 15 秒一次的清理移除。

## 当前页面与跟踪

人员列表显示文档、设置分类、侧栏、搜索、资源、插件页或弹窗。点击“跟踪”只打开对方当时所在页面一次，不持续跟随之后的切换，不执行对方的编辑操作。

可直接打开的页面使用思源原生入口；已经打开的侧栏不会被再次关闭。原生弹窗的关闭保护仍然有效。重命名、导出确认等没有安全公开入口的操作弹窗会打开其所在页面并提示手动打开；不会复制弹窗输入或提交动作。接收端缺少对应插件或资源时会提示无法打开。

## 指针与选中文字

每位参与者使用自己的颜色显示指针和名字。聚焦可编辑输入区时，指针标注“编辑中”；实际输入时标注“打字中”，停止输入约两秒后恢复。不发送输入内容，密码和私密输入不报告状态。本机鼠标靠近远端标记时，标记变为半透明。标记不接收鼠标事件。

正文文字按文档、块 ID 和字符偏移定位；行距、行尾和段落间距锚定相邻字符，空段落锚定对应块，保持正文内连续移动时可见。标题文字按字符定位。文档树使用笔记本 ID、文档 ID 和具体子控件，名称按文字字符定位，不按整行比例定位。各窗口按自己的换行和滚动重新计算坐标；鼠标不动而滚动页面时也会更新位置。

文本选区支持正向、反向、跨段落以及普通和嵌套列表。远端选区使用彩色高亮，本地选区保持不变，也不会自动跟随别人滚动。块级框选、图片、数据库单元格及复杂表格选择不在本版范围内。

数据库内的鼠标指针按数据库块、行和列匹配，单元格文字和空白都保留定位；行列重排、列宽变化、冻结列或可见卡片字段不会让指针串到同内容的其他单元格。接收端没有该字段、行被过滤、单元格隐藏或裁剪时隐藏；重复显示且无法唯一匹配时也隐藏。数据库表头和行外留白仍按所在组件匹配，尚未验证所有视图变化。

正文、文档树、反向链接、智能体等板块分别匹配；预览中的指针、选区和编辑框不会显示到正文。同一板块重复打开相同内容而无法唯一定位时隐藏。正文指针只显示在对应文档和内容上；文档不同、未加载、隐藏、滚出可见区或被遮挡时隐藏，不回退到窗口位置。设置、弹窗、侧栏、状态栏和标签栏等思源界面按对应控件定位：标签使用页面身份，侧栏使用功能类型，状态栏使用控件标识。窗口宽度、标签顺序或侧栏位置改变后会重新计算；找不到对应控件或存在歧义时隐藏。设置内容仅在相应分类可见时显示。

悬浮编辑工具栏、菜单、弹窗、正文边距、侧栏空白、名称后的留白、树缩进和分屏缝隙都按对应组件定位。文档所属的控件和留白只出现在同一文档；空白参照附近文字或组件边界计算。A、B 必须都有可见的对应目标；B 的目标隐藏、透明、被遮挡或已消失时不绘制。不能唯一匹配时也隐藏，不猜测位置。

图像按实际图像内容定位，适应图片留白与裁切；接收端已裁掉的部分隐藏。同源嵌入按内部组件定位，支持最多八层嵌套及各层独立滚动、平移、二维旋转、倾斜、缩放和翻转；可见边框单独定位，每层隐藏、透明、私有标记或遮挡都会隐藏内部指针。逐层累计祖先的二维变换，支持小数边框、内边距和 CSS zoom；三维与透视变换尚未支持。跨域嵌入和没有坐标接口的第三方自绘画布无法可靠识别内部目标，暂不绘制。原生关系图节点按节点身份与本地缩放、平移定位，空白要求两端图布局一致。系统文件选择器、操作系统菜单及其他原生窗口不属于思源网页插件可观察的范围。

原生 PDF 页面和缩略图按相同文件、页码和页面内容定位，适应两端不同缩放、旋转与滚动；标注仅在对应标注可见时显示。关闭缩略图侧栏、页面未渲染或文件已被替换时隐藏，避免画到另一个页面或正文中。

## 正在编辑的块

正文获得输入焦点时，光标所在块显示细边框和“某人正在编辑”，包含自己。同一块的多人名字合并显示；边框颜色采用其中一位参与者的颜色。这里的“正在编辑”表示编辑焦点仍停留在这个块，不代表一直在打字，也不代表占有编辑权限。

切换块时标记跟随，离开编辑区、窗口失焦或隐藏时清空。标记不接收点击，不改正文或本地选区。正常在线心跳会延续编辑状态，不需要静止时重复发位置包；异常断线后约 30 秒清除编辑状态；在线人数另按会话心跳清理。只有提供正文输入焦点和块 ID 的内容会显示编辑框。

编辑光晕位于编辑器内部，工具栏、菜单、浮动面板和弹窗按思源原生层级遮挡，不会穿到这些窗口上面。

## 同步频率

“协作显示设置”提供三档：低每秒最多 3 次、中每秒最多 10 次、高每秒最多 30 次，默认中档。保存后同一内核的所有窗口采用新频率，重启后保留。此设置只影响展示，不改变正文同步方式。

鼠标、滚动、选区或编辑焦点变化时才安排同步，连续事件合并并保留最后位置；状态相同不重复发送。空闲时不发送位置包，仍每 20 秒发送在线心跳，用来检测断线。

## 快捷键提示

其他窗口能短暂看到“某人 Ctrl+C”等组合键提示。只观察组合键，不传普通输入、密码框操作、剪贴板内容，也不在远端执行快捷键。连续输入按同步频率合并，只展示最新组合键。

## 遇到问题

| 情况 | 检查 |
| --- | --- |
| 顶栏无法获取协作状态 | 内核运行正常，各窗口启用同版插件并连接同一内核 |
| 指针或选区不可见 | 同一文档已加载，目标可见；选区显示需要 CSS Custom Highlight 支持 |
| 刷新后人数暂时偏多 | 是否打开了多个窗口、sessionStorage 是否可用；旧会话会超时清理 |
| 仍提示没有编辑权限 | 当前窗口可能仍运行旧版，确认更新后重新启用插件 |

协作显示断线不会由和弦阻止编辑。正文同步冲突和撤销结果由思源处理；和弦不再提供“仅撤销自己的操作”的保证，也不提供权限控制或备份。

报告问题时提供版本及复现步骤即可；请勿发送访问令牌、工作区配置或完整笔记。
