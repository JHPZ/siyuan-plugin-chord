# 使用和弦

和弦让连接同一个思源内核的多个窗口共享在线状态、光标和文本选区，并协调块的编辑权。

第一次使用时，建议开一篇临时文档和两个窗口：先选中文字，再分别编辑两段，最后各自撤销一次。确认操作符合预期后，再用到自己的笔记里。

## 安装与更新

插件目录固定为 `<工作空间>/data/plugins/siyuan-plugin-chord/`。解压后请检查：`plugin.json`、`index.js`、`kernel.js`、`index.css` 和 `i18n/` 都在这个目录中，而不是又套了一层同名文件夹。

启用后，顶栏笑脸图标的提示中应出现“和弦”、当前名字和在线数。点开菜单可查看人数、改名、调整同步频率，或撤销和重做自己的操作。

每个参与窗口都要加载同一版本。更新前先退出编辑，确认输入已保存；更新文件后，在各窗口重新启用插件或重新打开前端。个人历史会随插件卸载清空。

## 认识参与者

初次加入会得到一个四位大写字母名，例如 `KQAM`。名字可使用 1–24 个字符，不能与当前在线名字重复。这里的名字是协作称呼，不是经过验证的账号。

文档树在可见文档行上显示正在查看者，包含自己。前两名直接显示，更多人显示为 `+N`；完整名单保留在节点的可访问描述中。折叠目录展开后才会出现相应标记。

在线数按窗口统计。同一个窗口刷新会尝试复用身份、名字、颜色和最近查看的文档；同一人同时打开两个窗口仍算两名参与者。关闭后重新打开，或浏览器不允许 sessionStorage 时，身份可能重建。异常离开的旧会话在约 90 秒无心跳后，由最多每 15 秒一次的清理移除。

## 指针与选中文字

指针用每位参与者自己的颜色显示，名字跟在旁边。本机鼠标靠近远端指针或名字时，远端标记降为半透明，移开后恢复。标记不接收鼠标事件。

正文文字优先按块 ID 和字符偏移定位，文档树按行内比例定位。窗口宽度、换行和滚动不同，接收端会按自己的页面重新计算。发送端鼠标不动、只滚动滚轮时，也会更新锚点。

文本选区支持正向、反向、跨段落以及普通、嵌套列表。别人选中的文字以其颜色半透明高亮，自己的 Selection 不会被替换，也不会自动跟随对方滚动。块级框选、图片、数据库单元格及复杂表格选择不在本版范围内。

目标未加载、折叠、移出视口或被弹窗挡住时，远端指针会隐藏。图片、复杂表格等无法锚定字符的内容采用块内相对坐标。正常离开时会清空状态，未通知的指针与选区在约 5 秒后失效。

## 进入与退出编辑

| 动作 | 结果 |
| --- | --- |
| 单击正文、拖动选择、复制 | 保持浏览，不申请编辑权 |
| 双击正文块 | 向内核申请该块，获得确认后可编辑 |
| 他人正在编辑同一块 | 仍可阅读和复制，修改被阻止 |
| 按 Esc、单击另一块 | 退出编辑，先保存最后输入再主动放锁 |
| 切换文档、窗口失焦、页面隐藏 | 退出编辑并开始保存、释放流程 |

等待编辑权时，普通字符、粘贴和输入法输入不会被暂存重放；得到确认后再输入。块边界的普通退格/删除会在相邻块授权后补执行一次，连续按住不会积累延迟删除。等待期间移动光标、正文变化或授权失败，会取消这次补执行。

同一文档的不同块可分别编辑。父块与子块互相冲突；修改跨块选区时一次申请整组，有一块被占用就不会部分授予。

编辑锁每 3 秒续租，租期 15 秒。确认失效前，前端会提前停止使用权限。异常离线的锁最多约 16 秒清理。保存失败时不会主动放锁，但租约仍有期限；恢复连接后需要重新申请。

## 个人撤销与重做

| 入口 | 动作 |
| --- | --- |
| Ctrl+Z / 菜单“撤销我的操作” | 撤销当前窗口、当前文档的上一步 |
| Ctrl+Y / Ctrl+Shift+Z / 菜单“重做我的操作” | 重做对应个人操作 |

不必双击进入编辑再撤销。搜索框、改名等普通输入框保留各自的原生撤销。

连续一秒内、同块且内容首尾衔接的输入会合并。指针操作、光标导航、粘贴及输入法开始会分隔步骤。新编辑清空该文档的重做分支。每文档最多保留 100 步、约 1000 万字符操作数据；单步超过 200 万字符时保留阻断记录。

常规文字、格式更新以及块插入、删除、拆分可以重放。块移动、数据库、嵌入及同时替换父子快照的复杂转换暂不支持。遇到不支持的一步，记录保留，后面的旧步骤也不会被悄悄跳过。

如果所需块被别人占用，请等对方退出后再按一次。如果内容或位置已变，和弦会停止并保留记录，不做字符级合并。事务提交后响应丢失时，结果可能已经生效；此时会暂停重试，请刷新核对正文，避免重复执行。刷新也会清空个人历史。

## 调整同步频率

菜单“光标追踪设置”接受 1–30 的整数，默认 10 tick/秒。保存后同一内核下的所有参与窗口立即采用新频率，重启后保留。频率越高，流量和耗电通常越多。

这只调整指针与选区的同步，不影响编辑锁续租。一般可以先保留默认值。

## 遇到问题时

| 看到的情况 | 可以先做什么 |
| --- | --- |
| 顶栏提示无法获取协作状态 | 确认内核运行、插件在各窗口启用，且各窗口连接同一内核 |
| 单击后不能输入 | 双击目标块，等待编辑光晕出现 |
| 显示某人正在编辑，但对方已离开 | 等待租约清理，再双击申请；不要用刷新反复抢锁 |
| 指针看不见或选区没有高亮 | 确认同一文档已加载且目标可见；选区需要 CSS Custom Highlight 支持 |
| 刷新后的在线数暂时偏多 | 检查是否确有多窗口、sessionStorage 是否可用；异常旧会话会超时清理 |
| 撤销提示内容已变化 | 核对正文。记录仍在，但不会强行覆盖后续内容 |
| 提交结果无法确认 | 按提示刷新并核对正文，再继续编辑；不要重复提交同一步 |

如果仍可复现，请提供思源和插件版本，以及能复现问题的操作步骤。截图中的笔记正文和名字可以遮去；请不要附上工作区压缩包、访问令牌或完整配置文件。

## 协作的边界

内核管理的是锁与协作状态，当前插件接口并不提供覆盖所有写入入口的全局事务拒绝钩子。未启用和弦的前端、外部 API/MCP、其他插件、部分特殊编辑器和原生命令可能绕过它。

因此，和弦不能作为账号权限、文档隔离或数据备份使用。它也不是 CRDT / OT 文本合并引擎。让参与者使用同一版本、约定相同工作方式，依然是协作的一部分。
