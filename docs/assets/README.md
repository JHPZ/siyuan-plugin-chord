# 项目素材

`chord.svg` 是图标的可编辑源文件，`preview.svg` 是发布预览的可编辑源文件。根目录 `icon.png` 为 160 × 160，`preview.png` 为 1024 × 768，供思源读取。PNG 由源 SVG 在本地浏览器渲染导出，没有外部图片、客户数据或真实笔记截图。

图标用三条弦线和一条连线表达共同书写。预览采用纸色、深绿和少量铜色，配以中文衬线字与 Chord 字标。正文里的参与者颜色仍来自插件会话，不被这套资料配色覆盖。

预览中的 Lin、Qiao、Yue 及三行文字均为演示内容。保留“协作示意 · 非界面截图”标记，替换为实测截图时必须重新核对文案与隐私。

SVG 使用本地 Georgia、宋体和微软雅黑字体栈。源 SVG 在其他系统上可能有字形差异；发布包使用已经导出的 PNG，不要求用户安装这些字体。导出不分发字体文件。

素材随项目采用 MIT License。尺寸与文件大小由 `npm run check` 核对，修改 SVG 后应重新导出对应 PNG，并打开检查裁切、字形和标记位置。
